## Usage Guidelines

### Use Partner Version When:
- Job title includes "Partner", "Channel", "Alliance", "Ecosystem"
- Job description emphasizes go-to-market strategy
- Focus is on enabling partners vs building systems
- Companies: SaaS vendors, cloud platforms, tech companies with partner programs

### Use IT/Apps Version When:
- Job title includes "Director", "VP", "Manager" + "Business Systems/Applications"
- Job title includes "Architect", "ERP", "Functional"
- Job description emphasizes system implementation/optimization
- Focus is on building/running internal systems
- Companies: Any company with complex business systems needs

## Quick Updates

### To Update Both Versions:
1. Add new experience/education to BOTH files
2. Keep bullets consistent across both
3. Only headline, competencies, and skills should differ

### File Naming Convention:
- `Dave_Gilbert_CV_partner.yaml` - Partner roles
- `Dave_Gilbert_CV_it-apps.yaml` - IT/Apps roles
